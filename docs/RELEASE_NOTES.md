# リリースノート

## 2026-09-16 — 体験型入門コースと要件連動評価

Architecture Sandboxを、構成図を自由に描くツールから、初学者が部品の役割を段階的に学び、要件に沿って設計理由を説明する学習アプリへ更新しました。

### 新しい学習体験

- ホームを「部品の役割から学ぶ」と「設計課題に取り組む」の2つの入口に再編しました。
- Web Browser、App Server、RDBMS、Load Balancer、Distributed Cache、Message Queue、Worker、API Gatewayの8ステージを追加しました。
- 各ステージを「役割を体験する」「別の場面で練習する」「操作結果と理由を確認する」の流れに統一しました。
- 学習済みの部品だけを使えるReact Flowキャンバス、段階開放、進捗保存、復習、卒業課題を追加しました。
- 卒業課題の図と設計メモを自由設計へ引き継げるようにしました。

### 設計画面とコンポーネント

- 入門と自由設計で、部品カード、接続点、編集操作、Undo / Redoを共通化しました。
- 横長の部品を上から下へ配置し、直角の接続線と矢印でデータの向きを見やすくしました。
- 32種類の部品を目的から検索し、基本8種類へ絞り込めるようにしました。
- 各部品の「？」から、役割、接続例、利用場面、注意点、考える問いをポップアップで確認できます。
- 詳細プロパティを任意項目として整理し、部品の役割、接続、短い設計理由だけでも評価できるようにしました。
- 設計の参照切れ、停止時の到達性、変更差分をAI通信なしで確認する機能を追加しました。

### 要件定義とシナリオ

- 固定シナリオを2テーマ×3ケースへ拡張しました。同じ題材でも利用量、可用性、データ保持、予算などの重点が変わります。
- AIの回答で明らかになった条件を、質問と回答を根拠として保存するようにしました。
- 交渉で合意した仕様変更を版管理し、その後の会話と評価へ渡すようにしました。
- カスタムシナリオに、AIが条件を設定するガイド付きモードと、利用者が仕様を定義するモードを用意しました。
- 内部指示や非公開条件を求める入力をGeminiへ送る前にサーバーで拒否し、編集可能な文面から採点操作の指示を除外する処理を追加しました。

### AI評価

- 可用性、拡張性、安全性、保守性、コスト、実現性の6軸とレーダーチャートを維持し、ケースごとの重点配分で総合点を算出するようにしました。
- 要件定義・交渉で確認できた条件と未確認の条件を「聞き取り到達度」として表示します。
- フィードバックを「良い点・確認できたこと」「改善が必要な点」「まだ確認が必要なこと」に分けました。
- AIが参照した部品から設定へ戻れるようにし、変更後は古い評価の共有を停止します。
- 未記録を欠陥と断定しないこと、妥当な別解を認めること、実測していない性能・費用を保証しないことを共通ルーブリックへ追加しました。

### 保存、操作、アクセシビリティ

- 送信済みの会話、要件メモ、構成図をブラウザへ自動保存し、ホームから再開できるようにしました。
- 作業削除前にJSONファイルを直接保存できる導線を追加しました。
- 新しい設計情報を含むJSON v4と、旧Base64 / JSON形式の読み込みに対応しました。
- キーボードとタッチでの接続、フォーカス復帰、背景操作による誤削除の防止、スマートフォン向けレイアウトを改善しました。

### 配置と検証

- フロントエンドをCloudflare Workers Static Assets、APIをGCP Cloud Run（東京）へ移行しました。
- GitHub Actionsで、Terraform、Rust、frontend単体テスト、Playwright、production build、候補revisionのsmoke後に本番へ切り替える手順を整備しました。
- 本番の実Geminiで2テーマ×6設計×3回、計36評価を実施しました。用意した重大欠陥の検出、別解と未確認事項の区別、採点誘導の無効化を確認しています。
- Findyの外部AIで12設計をクロスレビューしました。別観点を得る用途には使える一方、入力済みの根拠を読み落とす例があり、正解判定や人間の専門家の代替には使わない方針としました。

### 既知の制約

- AI評価は設計学習の参考であり、実環境の性能、可用性、安全性、費用を保証しません。
- 人間のアーキテクチャ専門家による独立レビューは未実施です（0 / 2名）。
- 初学者による独力完走と、別題材への学習転移の検証は未実施です（0 / 5〜8名）。
- 学習記録は現在のブラウザへ保存され、端末間では同期しません。
- 旧AWSリソースの廃止は、このリリースには含みません。
