# デザイン調整の方針

## 採用する方向

2026-09-14のレビューを受け、元のアプリのディティールを整える方向に変更する。画面の構成、文言、タブ、シナリオカード、左右の部品一覧・要件メモを土台にする。別のブランドやデモ用の画面は増やさない。

ローカル確認先は `/`。以前の `/design-lab.html` からも現行アプリへ移動できる。

## 今回の調整

| 対象 | 調整内容 |
| --- | --- |
| 色 | 本番アイコンの青 `#2164E8` に主要操作を揃える。保存・評価の緑は `#258253`、メモは薄い黄色を保ち、文字・背景・境界線を共通化。部品の種別色と保存データは維持する。 |
| 文字 | 元のタイトルと日本語の文言を使用。トップの見出しを最大42pxにし、文字の影を除く。本文14〜15px、作業画面の見出し18〜20pxを基本にする。 |
| 寸法 | 通常ボタンは高さ38〜42px、入力欄・送信ボタンは50px。角丸は操作部品6〜8px、カード10px、吹き出し12px。 |
| カード | 幅を利用可能な領域に収め、広い画面では3枚を同じ高さで並べる。大きく浮き上がる動きと強い影を抑える。 |
| 設計画面 | 部品一覧232px・メモ240pxを基準に、狭い幅では縮小する。部品の行は36px以上。自動全体表示の拡大率は100%までとし、部品が少ないときも過度に拡大しない。手動ズームは維持。 |
| 会話・評価 | 会話の行間と吹き出し幅を整える。評価の構成とレーダーチャートを維持し、罫線・余白・塗りの濃さを調整する。 |
| 操作状態 | ホバー、キーボードフォーカス、選択、無効状態を揃える。シナリオカードとカテゴリ見出しはボタンとして操作できる。 |

## パネルと画面間の移動

- 要件メモは右側、コンポーネント一覧は左側から開閉する。初期状態は開き、タブ横のボタンから再表示できる。閉じてもメモ、未送信のチャット、部品一覧のカテゴリ状態を保つ。
- 開閉操作は、添付のArc風アイコンに合わせた角丸のパネル型アイコンに統一する。左パネルと右パネルは仕切り線の向きで区別し、操作名はツールチップと読み上げラベルで示す。
- 部品一覧はタップ・クリック・キーボードで追加できる。スマホでは追加後に一覧を閉じ、配置した部品を選択状態で見せる。もう一度部品をタップすると詳細を編集できる。PCのドラッグ配置も保持し、追加処理・グループ処理・個数上限を共通化する。
- PCで左パネルを開閉するときは、キャンバスの左端が移動した分だけ表示位置を補正する。構成図の画面上の位置、倍率、保存する座標を保つ。
- PCでは開いているパネルを作業領域の横に並べる。760px以下では作業領域に重ね、一度に一方だけ表示する。最初の会話画面ではメモ、設計タブに移ると部品一覧を表示する。閉じたパネルはボタンで再表示するまで閉じておく。
- スマホでパネルを開いている間は、背面の作業領域を操作対象から外す。閉じるボタン、背景タップ、パネル内でのEscapeで閉じ、表示切り替えボタンへフォーカスを戻す。
- ユーザーガイドは説明付きの目次から本文を開く。本文には「目次に戻る」と前後の項目への移動を用意し、戻ると選んでいた項目へフォーカスを戻す。画面の高さが足りない場合は本文だけスクロールする。
- 作業画面のヘッダーアイコンからホームへ戻れる。ホームのフッターには [morimizu.dev](https://morimizu.dev/) へのリンクを置く。

## 本番アイコン

本番の [Architecture Sandbox](https://sandbox.morimizu.dev/) とmainブランチの `OPEN A` アセットを使用する。トップは `/icons/01-open-a.svg`、作業画面のヘッダーは `/icons/01-open-a-small.svg`。favicon・Apple touch icon・manifestも本番と同じファイルを使用する。アイコンそのものの形状・配色を変更しない。

## 保持する動作

API、保存形式、シナリオ、AIとの会話・評価処理は既存のものを使う。コンポーネントの削除・接続、グループ操作、Shift + Enterでの改行、入力欄の1〜3行の伸縮、送信中のタブ移動、保存・読み込みを保持する。

変更はローカルと作業ブランチでレビューする。本番デプロイはこの作業の対象に含めない。

- 1280pxのガイド目次はスクロールなしで全項目を表示でき、390pxのパネルは左右に収まることを実画面で確認。スマホのタップ追加、PCのキーボード追加とパネル型アイコンも確認。
- ブラウザでトップ、会話、部品の追加とプロパティ、保存ファイルから読み込んだ構成図・評価、カスタム設定、操作ガイドを確認。評価表示の確認には明記したローカルのサンプルデータを使用し、外部AIは呼び出していない。
- 通常幅・900px・390pxで表示を確認。狭い画面でのタブの折り返しと設定画面へのスクロール位置引き継ぎを修正。検証後は画面幅の固定を解除。
