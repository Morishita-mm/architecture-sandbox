## 方針

学習者が変えるのは図の構成と実験の条件。要求の文章を自由入力させず、固定した具体的な場面を使う。

Web Browser / App Serverの体験・練習は右の操作パネルを廃止する。図のWeb Browserのボタンを押すと、要求が接続先へ進み、返事が戻って、そのカードに自動で表示される。別途「表示する」操作は不要。線を外して実行すると返事が届かないことを示す。

DBでは固定の記録を保存・再起動・読み出しして比べる。キャッシュでは固定のお知らせを更新する。負荷の変更、停止・再開、キャッシュの無効化、重複防止、仮想時間と再試行は実験結果に影響するため残す。卒業課題の理由・トレードオフの記述も残す。

## 互換性

以前の文章、保存した記録、クリア履歴、図は維持する。新しい実験操作の時点で、そのページの固定シナリオを適用する。以前の保存記録は、新しく保存するまでは読み出せる。保存形式のバージョンや既存フィールドを変更しない。
