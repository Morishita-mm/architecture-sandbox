## 初回の方針と範囲

2026-09-15のユーザー合意により、初学者の入口を「部品の役割から学ぶ」、経験者の入口を「設計課題に取り組む」に分ける。従来の自由設計は維持し、学習コースを通らなくても全コンポーネントを使用できる。

最初の実装は、短いメッセージを題材にした2章。接続・切断・送信・保存・再起動・読み出しを操作し、部品が必要になる理由を確かめる。用意した教材のルールをブラウザ内で実行し、AI APIは使用しない。実システムの性能や耐久性を測るシミュレーターではない。

- 第1章「要求を届ける」: Web BrowserとApp Serverの2種類。要求と返事の経路を表示し、接続あり／なしの結果を比較する。
- 第2章「記録を残す」: RDBMSを追加。アプリの一時記憶と、アプリとは別の保存先の違いを再起動と読み出しで比較する。この教材ではDB自体の故障やバックアップは扱わない。
- 各章は操作で得た観察と、役割を確かめる短い問いで完了を判定する。未接続は失敗として罰せず、理由と次に試す操作を示す。
- 学習進捗と教材の構成をブラウザに保存。設計プロジェクトのJSON契約と自動保存領域を変更しない。保存できない場合も学習を続けられる。
- 章の選び直し・やり直し・自由設計への退出はいつでも可能。全32種類の履修を自由設計の前提にしない。

## 実装上の判断

- 教材は独立した画面として遅延読み込みする。既存の自由設計エディターを改変して教材の制限を適用せず、教材内の限られた部品だけをHTML/CSSで表示する。教材内のReact Flowインスタンスは0。
- 接続は「つなぐ」「外す」の通常のボタンで操作し、ドラッグを必須にしない。部品は役割を大きく、正式名称を補足として表示する。色は自由設計と同様に、ブラウザは青、処理はオレンジ、保存は緑。
- 2つの構成の結果を観察した記録と、役割の問いへの回答で完了する。章を飛ばすこともでき、復習で構成を変えても過去の観察記録は残る。「この章をやり直す」は確認後に当該章だけ初期化する。
- `localStorage` の専用キー `architecture-sandbox:learning-course:v1` に、現在の章・入力・接続・教材の記録・観察済みの状態・回答を保存。入力は60文字まで、保存形式は上限と型を確認する。直前の動きの説明ログは再開時には復元せず、新たな操作で表示する。
- 読み込み不能な学習記録は、画面を開いただけで上書きしない。次の操作／保存再試行から新しい学習記録を保存する。保存失敗時は警告と再試行を表示し、画面上の学習を続けられる。学習記録はプロジェクトJSONに含めず、ブラウザデータを消すと失われる。
- 自由設計のサイドバーは全種類を初期表示し、基本8種類への絞り込みも残す。カテゴリの開閉・検索・説明の機能は継続。ホームの旧「はじめての方へ」は、教材の入口と区別して「設計のヒント」とした。
