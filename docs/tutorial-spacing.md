# お手本の配置とデータ移動の修正

2026-09-15。[Issue #17](https://github.com/Morishita-mm/architecture-sandbox/issues/17)。[図内ボタン化](fixed-scenario-tutorial.md)の利用後フィードバックを反映。

## 原因と方針

接続点間の距離が短いと、線の両端に確保する28pxの区間が重なり、描画経路が途中で逆方向へ折り返していた。例として縦20pxの接続で、Y座標が140 → 168 → 132 → 160の経路を再現した。移動するデータもこの経路をたどるため、「送信」中に往復して見えた。

下向きの経路では両端の区間を距離の半分までに制限し、途中の逆走をなくす。要求と応答は異なる再生ステップとして維持し、移動する印に進行方向の矢印を追加。説明は「要求（送信）」「返事（応答）」に揃える。

お手本の行間隔は120pxから入門2ステージで240px、その他は190pxへ拡大する。並列の列間隔は280pxから320pxへ拡大する。役割ごとの上下関係と、同じ段の並列アプリを維持する。スマートフォンの入門用キャンバスも420pxへ拡大し、余白の追加が縮小表示で失われないようにする。

再生時間は1移動1.2秒を維持。教材の流れを追うための速さであり、ボタンの応答待ち時間ではない。一時停止と前後移動、動きを減らす設定を引き続き利用できる。

## 既存データ

旧レイアウトの計算結果と全座標が一致する図のみ、読み込み時に間隔を更新する。手動の配置は保持する。「縦に整列」ではどの図も新間隔へ並べ直せ、Undoで取り消せる。教材の固定応答先の位置、構成の接続、採点用の検証状態、クリア履歴を変えない。保存形式の変更はない。
