# 評価レポートの表示整理

2026-09-16 / [Issue #18](https://github.com/Morishita-mm/architecture-sandbox/issues/18)

## 方針

総合点とレーダーチャート、6つの観点の数値を概要として先に示し、良い点・改善点・未確認事項、次に試す提案へ読み進める。基準は概要の下で開閉できる。点数だけでは理解しづらい用語に短い説明を添える。レーダーチャートはユーザーの希望に合わせて、結果を開いた直後から常時表示する。

緑の「良い点・確認できたこと」、橙の「改善が必要な点」、青の「まだ確認が必要なこと」を独立したカードにする。色だけに頼らず、見出しとアイコンでも区別する。PCでは良い点・改善点を並べ、狭い画面では縦に読む。

- [x] レーダーチャートを概要へ戻し、PC・スマホで開閉操作なしに見えるようにする

## データの扱い

API応答と保存形式、採点基準、各観点の重みは変更していない。`feedback`にある「確認した根拠」「重大な不足」「未確認事項」などの明示された見出しだけを使って表示を分ける。文章から独自に良し悪しを推測しない。見出しのない文章や引用・コードは残し、JSON保存には分割前の評価を使う。

AIが未確認事項を不足と分類するなど、評価そのものの品質はこの表示変更では解消しない。[Issue #13](https://github.com/Morishita-mm/architecture-sandbox/issues/13)で継続する。
