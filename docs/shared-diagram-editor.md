## 共通化した範囲

| 変更する内容 | 管理する場所 |
| --- | --- |
| 部品の外観・種類別の色・上下の接続点・選択表示 | 既存の `CustomNode.tsx`、`nodeStyles.ts`、共通CSS |
| React Flowの描画・線・矢印・背景・ズーム・キーボードのフォーカス | `DiagramCanvas.tsx` |
| ノード／線の変更・接続・追加時の選択・Undo/Redo・ドラッグ／削除の履歴統合 | `useDiagramEditor.ts`、`diagramEditing.ts`、`diagramHistory.ts` |
| 自由設計の会話・評価・要件メモ・グループ配置・モーダル中の操作制御 | `ArchitectureCanvas.tsx` |
| 学習パレット・停止の操作・経路ステップ・実験とクリア判定 | `LearningCanvas.tsx`、`StageStudio.tsx`、既存の教材モデル |
| 学習v4と共通エディタの相互変換、卒業時の部品データ | `courseEditor.ts`、`courseProject.ts` |

自由設計と学習は、同じ`DiagramCanvas`・`CustomNode`・`useDiagramEditor`を利用する。以前の学習専用ノード`LearningPart`とそのスタイル・接続点、学習独自の編集履歴を削除した。アプリ全体を巨大なモード切替コンポーネントにはせず、画面の目的に関わる操作は各画面へ残す。

停止・経路番号・固定された教材の応答先は、表示用Contextで共通ノードに伝える。経路番号などをノードの保存データへ追加しない。停止状態は学習用エディタのデータとして履歴に含め、v4へ戻す際は既存の`stopped`だけを保存する。ドラッグ中の位置は画面上で更新し、移動終了時に保存する。

接続点は自由設計と同じ上側が入力、下側が出力。操作領域はPCで20px、タッチで28px。初回の教材側の応答先は移動・削除できず、入力接続点だけを持つ。学習用の部品制限、接続上限と自己接続の禁止、実験・進捗の仕様は教材側で維持する。

キャンバスの高さ・初期倍率、パレット配置、学習用の操作欄と自由設計の詳細設定は、画面の用途に合わせて残す。既存の部品位置、学習v4・旧学習記録、プロジェクトJSONの契約は変更しない。

## 今後の調整箇所

部品の見た目を調整する場合は共通ノード、編集操作を変える場合は共通エディタに変更を集める。学習上の配置数・開放順・実験条件は教材側だけで調整する。学習の図と自由設計はデータを別保存するが、同じ表示・編集実装を使う。
